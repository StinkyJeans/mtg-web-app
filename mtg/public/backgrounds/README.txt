Put your battlefield picture here and name it:  battlefield.jpg

- Any size works, but a wide picture (for example 1920 x 1080) looks best.
- The game uses it behind the battlefield whenever you have not chosen a different background
  with the "Background" button inside the game.
- To use a PNG instead, you can still choose it from inside the game ("Choose a picture from your computer").

HOME PAGE WALLPAPER
Put your own live wallpaper here and name it  home  with its own ending:
  home.mp4  or  home.webm   (a video: it loops, silently, behind the home page)
  home.gif  home.webp       (an animated picture)
  home.png  home.jpg        (a still picture)
Refresh the page (Ctrl+Shift+R). Without a file, the built-in animated background is shown.
The "Animations" switch at the top turns the movement off.
